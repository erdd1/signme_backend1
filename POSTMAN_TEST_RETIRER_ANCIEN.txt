PRÉPARATION
===============================================================================

1. Obtenir votre Bearer Token (si vous l'avez pas)
   
   POST http://localhost:8000/api/v1/auth/login
   Content-Type: application/json
   
   {
     "email": "pasteur@email.com",
     "password": "votre_password"
   }
   
   ✅ Copier la valeur de response.data.token

2. Dans Postman:
   - Aller à l'onglet "Authorization"
   - Type: Bearer Token
   - Token: <coller votre token>

===============================================================================
TEST AVANCÉ: PLUSIEURS DÉSIGNATIONS
===============================================================================

Scénario:
- Un même ancien a 2 désignations (juin + juillet)
- On retire seulement celle de juin
- L'ancien devrait RESTER de service (car il en a une autre)
- Puis on retire celle de juillet
- L'ancien devient finalement NON de service

───────────────────────────────────────────────────────────────────────────

ÉTAPE 1: Créer 2 désignations

POST /api/v1/anciens-designations
{
  "ancien_id": 5,
  "mois": 6,
  "annee": 2026,
  "jours_travail": null,
  "horaire_debut": null,
  "horaire_fin": null
}
✅ Copier ID: 42

POST /api/v1/anciens-designations
{
  "ancien_id": 5,
  "mois": 7,
  "annee": 2026,
  "jours_travail": null,
  "horaire_debut": null,
  "horaire_fin": null
}
✅ Copier ID: 43

───────────────────────────────────────────────────────────────────────────

ÉTAPE 2: Vérifier l'état AVANT

GET /api/v1/users/5

✅ est_de_service = true
✅ Vérifié dans anciens-designations:
   - Juin: 1 ancien
   - Juillet: 1 ancien

───────────────────────────────────────────────────────────────────────────

ÉTAPE 3: Retirer la 1ère désignation (juin)

DELETE /api/v1/anciens-designations/42

✅ Réponse 204

───────────────────────────────────────────────────────────────────────────

ÉTAPE 4: Vérifier APRÈS retrait de la 1ère

GET /api/v1/anciens-designations?mois=6&annee=2026

✅ total_designes = 0 (juin n'a plus personne)

GET /api/v1/anciens-designations?mois=7&annee=2026

✅ total_designes = 1 (juillet a toujours Jean)

GET /api/v1/users/5

✅ est_de_service = TRUE ✅ (TOUJOURS true car il a la désignation de juillet)

───────────────────────────────────────────────────────────────────────────

ÉTAPE 5: Retirer la 2ème désignation (juillet)

DELETE /api/v1/anciens-designations/43

✅ Réponse 204

───────────────────────────────────────────────────────────────────────────

ÉTAPE 6: Vérifier APRÈS retrait de la 2ème

GET /api/v1/anciens-designations?mois=7&annee=2026

✅ total_designes = 0 (juillet aussi vide)

GET /api/v1/users/5

✅ est_de_service = FALSE ✅ (MAINTENANT false car plus de désignation)

===============================================================================
TROUBLESHOOTING
===============================================================================

❌ Erreur 404: Not Found
   → L'ID n'existe pas. Vérifier l'ID copié à l'ÉTAPE 1

❌ Erreur 403: Forbidden
   → Vous n'êtes pas pasteur/admin de cette église
   → Vérifier le Bearer Token

❌ Erreur 422: Validation Error
   → ID doit être un integer (ex: 42 au lieu de "42")

❌ est_de_service reste TRUE
   → L'ancien a d'autres désignations actives
   → Vérifier avec GET anciens-designations pour les autres mois
